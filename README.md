# 🚀 BA AI4BA MASTER WORKFLOW TOOLKIT

> Được tổng hợp và chuẩn hóa từ toàn bộ các gói Skill AI4BA: **Brainstorming**, **Diagramming**, **Wireframe HTML**, **User Guide** cùng bản cập nhật bổ sung từ **BA-Kit (ai4ba-skills)**.

## 📌 Bắt Đầu Nhanh

1. **Xem Cẩm Nang Chi Tiết & 64 Skill Explanations**: Mở file [`HUONG-DAN-BA-KIT.html`](./HUONG-DAN-BA-KIT.html) trực tiếp trên trình duyệt.
2. **Xem Hướng Dẫn Quy Trình Master Chi Tiết**: Mở file [`WORKFLOW-BA-MASTER.md`](./WORKFLOW-BA-MASTER.md).
3. **Mở BA Skill Interactive Dashboard**: Mở file [`index.html`](./index.html) trực tiếp trên trình duyệt để tra cứu visual workflow, copy prompt 1-click và xem mẫu ví dụ.
4. **Đọc 10 Chương Hướng Dẫn Nâng Cao**: Xem tại thư mục [`huong-dan/`](./huong-dan/).

## ⚡ Tóm Tắt Các Giai Đoạn Quy Trình BA

- **Giai đoạn 1: Brainstorm & Requirements** (`/brainstorm`, `/brd`, `/urd`, `/prd`, `/srs`, `/userstory`, `/ac`) — Đột phá ý tưởng, xây dựng BRD, PRD, Feature Spec 12 mục & User Story.
- **Giai đoạn 2: Diagram & Business Modeling** (`/user-flow`, `/bpmn`, `/sequence`, `/usecase-diagram`, `/erd`, `/state`, `/activity`, `/activity-swimlane`) — Trực quan hóa luồng công việc & sơ đồ kiến trúc.
- **Giai đoạn 3: Wireframe HTML & Figma Drawing** (`/wireframe-html`, `/wireframe-ascii`, `/prototype-html`, `/figma`) — Tạo giao diện mẫu tương tác HTML và vẽ tự động lên Figma Desktop qua MCP Reqwise.
- **Giai đoạn 4: API, Testing & User Guide** (`/api-design`, `/api-test`, `/test-cases`, `/test-checklist`, `/userguide`) — Đặc tả & kiểm thử API, test checklist và đóng gói Hướng dẫn Sử dụng Web Guide Viewer.
- **Giai đoạn 5: Quản trị & Đồng bộ** (`/jira`, `/confluence`, `/cr`, `/gap`, `/kg`, `/doc-drift`, `/export`) — Quản lý Change Request, Knowledge Graph và Jira/Confluence.
